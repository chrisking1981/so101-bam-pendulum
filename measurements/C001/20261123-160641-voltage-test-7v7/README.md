# Voltage test: RD6006 at 7.70 V

These are the 5 runs that had deviated, replayed with the RD6006 set to 7.70 V (7.68 V measured at the RD6006 output; the servo register read 7.3 V median). The profile was off in EEPROM. Afterwards the RD6006 was set back to 7.40 V (7.39 V measured). These runs are as good as the 7.4 V re-runs, so voltage was not the cause. `vin` is logged as 7.7.
